# DE Contest 3 — Task & Performance Tracker

## Run it
1. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
2. Double-click `index.html` to open it in a modern browser. No build step or installation is required.
3. Tick syllabus topics as you complete them.
4. Log study sessions with time spent, attempted/correct answers, confidence, and a short reflection.

## Features
- 13 lecture sections with topic-level checkboxes
- Overall completion and lecture completion progress
- Study session logging and accuracy calculations
- Total study minutes, session count, and confidence summary
- Recent session history with delete controls
- Automatic saving in browser localStorage
- Export progress as a JSON backup
- Responsive layout for desktop and mobile

## Notes
- Progress is saved in the browser/device where you open the page. It does not sync between devices.
- Google Fonts are loaded online; the interface falls back to local sans-serif fonts if unavailable.
- The reset button clears saved progress and sessions from this browser.
